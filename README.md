Smart Farm Management System is an AI-powered smart agriculture platform designed for real-time monitoring of soil and environmental parameters in modern farming.

The platform simulates and analyzes real-time telemetry data (Temperature, Soil Moisture, Wind Speed, Light Intensity, and Soil EC/Nutrient Levels) received from field-deployed IoT devices. Leveraging an integrated AI advisor, it provides farmers with automated biological analysis and actionable yield recommendations.

---

## 🚀 Key Features

* **📊 Real-Time Telemetry Tracking:** Dynamic monitoring of field-level sensor data (Temperature, Moisture, Wind, Light, Soil EC).
* **🤖 Generative AI Advisor Integration:** Automated biological analysis and warning/recommendation generation based on real-time sensor metrics and crop types.
* **🔐 Authentication & Role-Based Access Control:** Secure authentication, authorization, and personalized field/device management powered by Spring Security.
* **🌱 Field & Device Architecture (CRUD):** Dynamic field creation, update, deletion, and IoT device mapping mechanics.
* **🔔 Notification System:** Real-time user notifications triggered by AI analyses and environmental threshold breaches.

---

## 🛠️ Tech Stack

* **Backend:** Java 17, Spring Boot 3, Spring Data JPA, Spring Security
* **Frontend / Template Engine:** Thymeleaf, HTML5, CSS3, JavaScript (Fetch API)
* **Database:** PostgreSQL
* **Integrations:** RESTful APIs, Spring RestTemplate, Jackson JSON Parser
* **Tools & Build:** Lombok, Maven, Git, GitHub

---

## 🏗️ Architecture & Core Workflow

1. **Telemetry Simulation:** Sensor data for field-connected IoT devices is updated in real time via the `/api/fields/{id}/telemetry` endpoint.
2. **AI Analysis Engine:** Collected metrics across 5 core sensor parameters (Temperature, Moisture, Wind, Light, EC) are processed alongside crop metadata and sent to the AI model via `AiService`.
3. **Decision Support:** Concise, 2-sentence technical recommendations generated by the AI model are persisted via `NotificationRepository` and rendered on the user interface.
